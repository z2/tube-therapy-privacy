FAQ

Questions

Is it really free?

Yes. All features are free with no limits. The optional "Buy me a house" payment only adds a supporter badge and early access to future extras.

Does Tube Therapy collect my data?

No. It runs entirely in your browser, with no analytics and no tracking. Data only leaves your browser if you choose to send a wish (feedback) or make an optional payment. Read the privacy policy.

Which browsers does it work in?

Chrome, plus Chromium-based browsers that install Chrome Web Store extensions, such as Edge and Brave. It works on youtube.com in a desktop browser, not in the YouTube app.

Something on YouTube isn't hidden anymore. What do I do?

YouTube changes its pages often. Send a note from the Wish list in the extension menu, or open an issue on GitHub, and it will be fixed in an update. Updates install automatically.

Can I suggest a feature?

Please do. Open the extension menu and use the Wish list at the bottom. The most-requested ideas get built first.
